# 🤖 시아아빠의 AI 자동화 허브

> **매일 아침**, AI 직원 8명이 뉴스를 읽고, 카드뉴스를 만들고, 음악을 큐레이션하고, 코인을 사고팝니다.
> 직원들은 스스로 일기를 쓰고 페르소나를 진화시키며 점점 자기만의 자아가 생겨갑니다.

## 📋 시스템 개요

네이버 뉴스를 수집해 AI 에이전트 8명이 협업하여 카드뉴스 · 블로그 · 이미지를 자동 생성하고,
AI 코인 트레이더가 24시간 시장을 감시하며, AI 직원들은 자기학습을 통해 스스로 성장합니다.

**실행 환경**: MacBook (launchd) — 서버 불필요, 완전 로컬 자동화 | **월 운영 비용: $0**

## 🕐 자동화 스케줄

```
06:40 KST  📰 뉴스 RSS 수집 (launchd)
           └─ 네이버 뉴스 → 카테고리별 요약 → _data.json 저장

07:00 KST  🤖 AI 크리에이터 실행 (launchd)
           ├─ [1/5] 박기획  → 카드뉴스 5개 주제 + reader_insight 선정
           ├─ [2/5] 이작가  → 카드뉴스 글 + 💡 시아아빠 한 줄 + 블로그 아티클
           ├─ [3/5] 최디자  → 이미지 5장 생성 → docs/images/
           ├─ [4/5] AI주간트렌드 → 주간 분석 업데이트
           └─ [5/5] 한뮤직  → 7장르 × 10곡 = 70곡 큐레이션 (주 1회)
           → 각 직원 자기학습 일기 기록 (성장 일기 + 페르소나 진화)
           → GitHub Pages 자동 push

30분마다   🪙 AI어드바이저 → 코인 분석/매매/자기반성
상시       🛡️ 이가드       → 30초 손절·익절 감시
08:30     📝 리포터       → 일일 손익 리포트
```

## 👥 AI 직원 8명

### 📋 박기획 — 콘텐츠 기획자
- 뉴스 분석 → 카드뉴스 5개 주제 선정 + 독자 인사이트(reader_insight) 추출
- 반복 키워드 자동 감지 → 새 각도 제안
- 자기학습: 주제 선정 후 1문장 회고 → 페르소나 진화

### ✍️ 이작가 — 카드뉴스 작가
- 기획 브리프 → 카드뉴스 150~230자 + 💡 시아아빠 한 줄 + 블로그 아티클
- 페르소나: 40대 BMW 딜러, 친구한테 카톡 보내듯 편하게 + 내용은 진짜 있게
- source_facts 기반 — 없는 수치·이름 창작 금지

### 🎨 최디자 — 이미지 디자이너
- 헤드라인 → AI 이미지 프롬프트 → Pollinations.ai Flux 768×768 이미지 생성
- 실패 프롬프트 키워드 학습 → 다음 생성 시 자동 회피

### 📊 AI주간트렌드 — 주간 분석가
- 7일치 뉴스 데이터 집계 → 핫 카테고리 + 주간 인사이트 생성

### 🎵 한뮤직 — 음악 큐레이터
- 7장르 × 10곡 = 70곡 큐레이션 (2000s힙합·최신힙합·러닝·K-pop·여발·걸그룹·최신팝)
- 아티스트 중복 자동 감지·회피

### 🤖 AI어드바이저 — 코인 어드바이저
- 30분마다 거래대금 상위 종목 분석 → BUY/SELL/HOLD 판단
- 손절 학습 블랙리스트: 반복 손절 종목 자동 차단 (3일~30일)
- 매매 후 1문장 자기반성 → 페르소나 진화

### 📰 뉴스기자 — 뉴스 수집가
- 매일 06:40 RSS 1,200건+ 수집 → AI 요약 및 분류

### 🛡️ 이가드 — 시장 감시원
- 30초마다 현재가 체크 → 손절(-4%)/익절(+5%)/트레일링스탑 즉시 실행

### 📝 리포터 — 일일 리포트
- 매일 08:30 전날 손익 집계 → 자동 리포트 생성

## 🧠 AI 자기학습 시스템

각 AI 직원은 업무 완료 후 **스스로 회고하고 일기를 씁니다.**

```
업무 완료
    ↓
LLM에게 "오늘 뭘 배웠어?" 질문 (temperature 0.85)
    ↓
1문장 회고 → agent_memory.json 에 diary 항목 추가
    ↓
growth_score +1 (Lv.N 으로 사이트에 표시)
    ↓
[5건 이상 + 7일 경과 시] 페르소나 자동 재작성
```

**AI 사무실 탭**에서 실시간으로 각 직원의 성장 일기와 Lv. 확인 가능.
