# 🤖 시아아빠님의 AI 크리에이터

> 매일 아침, AI 직원들이 뉴스를 읽고 콘텐츠를 만들어 노션에 올려드립니다.

---

## 📋 시스템 개요

노션에 자동 수집된 뉴스레터를 바탕으로, 역할이 다른 AI 에이전트들이 협업해
카드뉴스 5개 + 블로그 아티클 + 이미지 5장을 자동 생성하고 노션에 업로드합니다.

---

## 🕐 자동화 스케줄

```
06:00  📰 뉴스레터 수집 시작
         네이버 뉴스 API → 8개 카테고리 수집
         Groq AI → 카테고리별 요약 + TOP 3 선정
         → 노션 업로드 + .md / _data.json 로컬 저장

06:30  🤖 AI 크리에이터 시작
         기획자 → 작가 → 디자이너 → 노션 퍼블리셔
         금요일엔 주간 브리핑도 자동 추가
         각 단계 실패 시 최대 3회 자동 재시도

~07:30  ✅ 모든 작업 완료
         📱 ntfy 앱으로 완료 알림 수신 (JSON 방식)
```

## 👥 AI 직원 소개

### 🎯 기획자 — 박기획

> "오늘 어떤 뉴스가 사람들 마음을 움직일까요?"

**역할**: 뉴스레터 전문을 분석해 카드뉴스와 블로그에 최적화된 콘텐츠 브리프 작성
**모델**: Groq — Llama 3.3 70B
**성격**: 트렌드에 민감하고 독자 심리를 꿰뚫는 10년 경력의 디지털 콘텐츠 기획자
**담당**:
- 오늘 뉴스 중 핵심 뉴스 **5개** 선정 (중복 주제 자동 금지)
- 각 뉴스의 각도(angle), 톤, 키워드 기획
- 블로그 아티클 주제 1개 선정

**출력**: JSON 형식의 콘텐츠 브리프

---

### ✍️ 작가 — 이작가

> "독자가 손을 멈추고 읽게 만드는 첫 줄, 제가 씁니다."

**역할**: 기획자의 브리프를 받아 카드뉴스 글과 블로그 아티클 작성
**모델**: Groq — Llama 3.3 70B
**성격**: SNS 감성과 블로그 깊이를 모두 갖춘 전문 저널리스트
**담당**:
- 카드뉴스 글 **5개** (이미지 먼저 → 글 아래 구조)
  - 훅 → 배경 → `[사실]` 팩트 → `[분석]` / `[전망]` 레이블 → 출처 명시 → 해시태그 20개
  - 최소 500자 이상
- 블로그 아티클 1개 (마크다운, 1500자+, 소제목 4개 이상)

**출력**: 카드뉴스 5개 + 블로그 아티클

---

### 🎨 디자이너 — 최디자

> "글보다 먼저 눈을 사로잡는 이미지, 제 전문입니다."

**역할**: 뉴스 헤드라인에 맞는 이미지 프롬프트 생성 → AI 이미지 생성 → 노션 업로드
**모델**: Groq — Llama 3.3 70B (프롬프트 생성) + Stable Horde (이미지 생성)
**성격**: Cinematic editorial 스타일을 추구하는 SNS 카드뉴스 전문 디자이너
**담당**:
- 헤드라인에 맞는 영문 이미지 프롬프트 생성 (Cinematic / editorial photography 스타일)
- Stable Horde(무료)로 **768×768 이미지 5장** 생성
- freeimage.host 업로드 → 노션 임베드용 공개 URL 획득

**출력**: 이미지 5장 (로컬 저장 + 노션 임베드)

---

### 📤 노션 퍼블리셔 — 정퍼블

> "만들어진 콘텐츠를 가장 보기 좋게 정리하는 건 저의 몫입니다."

**역할**: 모든 에이전트의 결과물을 받아 노션 페이지로 통합 업로드
**모델**: 없음 (Notion API 직접 호출)
**성격**: 꼼꼼하고 깔끔한 콘텐츠 관리 담당자
**담당**:
- **새 페이지 생성** (매일, 기존 페이지에 덮어쓰지 않음)
- 상단: 카드뉴스 5개 (이미지 → 글 순서) + 블로그 아티클
- 하단: 오늘 수집된 뉴스 목록 (출처 레이블 + 기사 링크 포함)

**출력**: 노션 페이지 1개 (제목: 🤖 YYYY년 MM월 DD일)

---

### 📅 주간 브리퍼 — 한주간

> "한 주를 5분으로 요약합니다. 바쁘신 분들을 위해."

**역할**: 매주 금요일, 이번 주 뉴스레터 5일치를 읽고 주간 종합 브리핑 생성
**모델**: Groq — Llama 3.3 70B
**성격**: 넓은 시야로 주간 트렌드를 읽는 시니어 뉴스 큐레이터
**담당**:
- 월~금 뉴스레터 .md 파일 수집
- 주간 TOP 5 뉴스 선정
- AI/기술, 경제/시장, 자동차/BMW 섹션별 요약
- 한 주 인사이트 작성

**출력**: 주간 브리핑 노션 페이지 (제목: 📅 주간 브리핑 — MM/DD ~ MM/DD)
