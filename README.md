## 📰 뉴스 수집 + 🤖 AI 크리에이터

RSS 피드로 뉴스를 수집하고, AI 직원들이 협업해 콘텐츠를 자동 생성합니다.

- **첫 번째 카드뉴스**: 반드시 자동차/BMW/전기차 관련
- **source_facts 기반**: 원문에 없는 수치·사실 창작 금지
- **💡 시아아빠 한 줄**: 독자가 뉴스를 읽고 당장 취해야 할 행동 1문장 (2중 안전망으로 누락 방지)
- **품질 5단계 후처리**: 블랙리스트 → 제목-본문 일관성 → 문장 품질 → 해시태그 위치 → 해시태그 수
- **이미지 실패 시** fallback 이미지 자동 대체 (None 노출 없음)

### 자동화 흐름

```
06:40 KST  📰 뉴스 수집 (com.siadad.newsletter)
               newsletter_naver.py — RSS 8개 카테고리
               → YYYY-MM-DD.md + YYYY-MM-DD_data.json

07:00 KST  🤖 AI 크리에이터 (com.siadad.aicrew)
           │
           ├─ 뉴스 데이터 확인 (없으면 긴급 수집 폴백)
           ├─ [1/6] 📋 박기획  — 뉴스 5개 선정 + reader_insight 추출
           ├─ [2/6] ✍️  이작가  — 카드뉴스 5개 + 💡 한 줄 + 블로그 아티클
           ├─ [3/6] 🎨 최디자  — Pollinations.ai 이미지 5장 (768×768)
           ├─ [4/6] 🎵 한뮤직  — 7장르 × 10곡 큐레이션 (주 1회)
           ├─ [5/6] 📊 AI주간트렌드 — 7일치 뉴스 인사이트 (월요일만)
           └─ [6/6] 📤 퍼블리셔 — GitHub Pages 자동 push
           → 각 직원 자기학습 일기 기록 (성장 일기 + 페르소나 진화)

~07:30 KST  ✅ 완료
```

### AI 직원 소개

| 직원 | 역할 |
|------|------|
| 📋 박기획 | 뉴스 5개 선정 (경제/산업/기술/국제 최소 3개), 지자체·소규모홍보 제외 |
| ✍️ 이작가 | 카드뉴스 5개 + 블로그 아티클, 💡 시아아빠 한 줄 필수 삽입 |
| 🎨 최디자 | Pollinations.ai Flux 이미지 5장, 실패 시 fallback 자동 대체 |
| 🎵 한뮤직 | 7장르 × 10곡 = 70곡, 주 1회 큐레이션 |
| 📊 AI주간트렌드 | 7일치 뉴스 분야별 집계 + Gemini 인사이트 브리핑 (월요일) |

## 🪙 AI 코인 자동매매

빗썸 KRW 마켓 거래대금 상위 종목을 분석하고 Groq AI가 매매를 자동 실행합니다.

**라이브 대시보드**: [siadaddy.github.io/youngs](https://siadaddy.github.io/youngs/) → 코인 트레이더 탭

### 매매 흐름

```
매 30분 (하루 48회)
│
├─ Daily Drawdown 체크 → 일일 손실 한도 도달 시 당일 봇 정지
├─ 블랙리스트 현황 출력 → 반복 손절 종목 제외
├─ 고점 갱신 + 손절(-4%) / 익절(+5%) / 트레일링스탑 / 8h 강제청산 체크
├─ 빗썸 KRW 24h 거래대금 20억 이상 종목만 선별
├─ 블랙리스트·스테이블코인 자동 제외
├─ 30분봉 RSI·MACD·볼린저밴드·ADX·변동성돌파 계산 (병렬 5개)
├─ 스코어링 → 상위 15개 Groq AI에 전달
├─ AI 오판 차단 필터 (실제 수익률 확인)
├─ 빗썸 시장가 주문 실행
├─ SELL 완료 → 시장 재수집 후 즉시 매수 기회 재탐색
├─ AI어드바이저 자기반성 1문장 → advisor_memory.json 저장
└─ docs/trades.json → GitHub Pages push

상시  🛡️ 이가드(price_guard.py) — 30초마다 현재가 감시 → 손절/익절 즉시 발동
08:30 📝 리포터 — 전날 손익 집계 → 일일 리포트 자동 생성
```

### 기술 지표 & 스코어링

| 지표 | 설정 | 매수 점수 | 매도 점수 |
|------|------|----------|----------|
| RSI | 14봉 (30분봉) | 20~35: +2 / 35~50: +1 / **<20: 0 (급락 중)** | >65: -1 / >75: -2 |
| MACD | 12/26/9 | 골든크로스: +2 / 상승: +1 | 데드크로스: -2 / 하락: -1 |
| 볼린저밴드 | 20/2σ | 하단: +2 / 중하단: +1 | 상단: -2 / 중상단: -1 |
| ADX | 14봉 | ≥20 추세 있음 (매수 허용) | <20 횡보 (매수 금지) |
| 변동성 돌파(VB) | K=0.5 (일봉) | 거래량+20% 동반: +2 / 미동반: +1 | — |

### 안전장치

| 기능 | 기준 |
|------|------|
| 손절 | 매수가 대비 -4% 자동 매도 |
| 익절 | 매수가 대비 +5% 자동 매도 |

| 종목 쿨다운 | 손절 후 해당 종목 6시간 재진입 금지 |
| 전역 쿨다운 | 손절 후 모든 종목 4시간 매수 금지 |
| Daily Drawdown | 일일 누적 손실 -7,500원 초과 시 당일 봇 정지 |
| 거래대금 필터 | 24h 거래대금 20억원 미만 잡코인 분석 제외 |
| 3중 감시 | price_guard(30초) + main.py(30분) + AI 오판 차단 필터 |
